### Выводы
1. C# требует явного указания типа переменной при объявлении, в отличие от Python.
2. Код C# преобразуется в IL-код, который затем CLR переводит в машинный код с помощью JIT-компиляции.
3. Git и GitHub позволяют отслеживать изменения, возвращаться к старым версиям и синхронизировать проект.

| Характеристика | C# / .NET |
| :--- | :--- |
| Платформа | .NET (CLR) |
| Компиляция | C# → IL-код → машинный код |
| Запуск | `dotnet run` |
| Тип переменной | Указывается явно: `int x = 5;` |
| Вывод в консоль | `Console.WriteLine("текст")` |
| Ввод от пользователя | `Console.ReadLine()` |
| Интерполяция строк | `$"Привет, {name}!"` |
| Целочисленное деление | `10 / 3 = 3` |
| Дробное деление | `(double)10 / 3 = 3.333...` |
| Математические функции | `Math.Abs()`, `Math.Pow()`, и др. |

### Ответы на вопросы:
1. `Write()` выводит текст без переноса строки, а `WriteLine()` — с переносом на новую строку.
2.  Возникнет ошибка компиляции, так как тип `int` предназначен только для целых чисел.
3. Потому что оба числа — целые (`int`), и C# выполняет целочисленное деление. Для дробного результата нужно привести одно из чисел к `double`: `(double)10 / 3`.
4. `var` позволяет компилятору самому определить тип переменной при объявлении. В Python типизация динамическая (тип может меняться), а в C# тип фиксируется один раз.
